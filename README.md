# MSc Econometrics

Python exercises and datasets for the MSc Econometrics tutorials.

The notebooks and datasets are in [Notebooks](Notebooks/), organised into tutorial subfolders. Download this repository as a ZIP and extract it, then upload the enclosed `Notebooks` folder to Google Drive > My Drive.

Open a notebook with Google Colab and run all cells, starting with **Environment setup**. Authorize Google Drive access when prompted. See [the notebook instructions](Notebooks/README.md) for other folder locations and local Jupyter use.

## Tutorial sheets

- [Tutorial 1 - Prices, return distributions and rolling inference](Tutorials/Tutorial%201.pdf).

## Notebooks

- [Financial Returns](Notebooks/Financial_Returns/): prices and returns, rolling equity premium, and tail risk / VaR.

- [OLS](Notebooks/OLS/): simple and multiple regression of energy-sector returns on the market and Brent; heteroskedasticity and robust inference; Monte Carlo simulation; rolling CAPM; and Okun's law with full-sample and rolling linear regressions.

- [Time Series](Notebooks/Time_Series/): autocorrelations and the Ljung-Box test for daily US market returns in 2021-2025; pre-2020 US real GNP growth dynamics; AR(1)/AR(3), persistence, model-implied oscillations and next-quarter forecasts, with a short comparison through 2025.

  Tutorial VII uses official Federal Reserve EUR/USD quotations for monthly
  unit-root tests. Tutorial VIII covers daily volatility clustering, ARCH(1)
  moments, ARCH/GARCH estimation and forecasts using the same official source.

Each tutorial includes its data alongside the notebooks.
